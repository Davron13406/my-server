## Результат
`npm test` успешно проходит в текущей среде.

## Что нельзя подтвердить в этой среде
- Интеграционную работу PostgreSQL и хранилища сессий.
- Реальную регистрацию, вход, покупки и сохранение данных через HTTP.
- GPS на физическом телефоне и в браузере.
- Адаптивность интерфейса на разных экранах и полный пользовательский сценарий.

Для этих проверок нужен запуск проекта на компьютере с Node.js 20+, Docker Desktop (или PostgreSQL), установленными npm-зависимостями и браузером.


## Следующая итерация: PWA и офлайн-очередь
- Добавлены manifest и Service Worker для кэширования оболочки приложения.
- Добавлена очередь тренировок в IndexedDB с синхронизацией после события online и при успешном входе.
- Очередь не выдаёт XP/коены локально: награды начисляет сервер после успешной синхронизации.
- Ограничение: без сети нельзя выполнить новый вход, получить серверный профиль, совершать покупки или синхронизировать GPS.
- Нужны браузерные проверки на HTTPS/localhost и проверка реального отключения сети; в текущей среде они не выполнялись.


## Итерация: надёжность офлайн-синхронизации
- Добавлен UUID запроса для каждой тренировки; он сохраняется в локальной очереди и передаётся серверу.
- Сервер хранит ключ запроса с уникальностью на пользователя и повторно возвращает результат уже обработанной записи, не начисляя награды повторно. Проверка выполняется под блокировкой строки профиля, чтобы одновременные повторы не задваивали XP/коены.
- Добавлена SQL-миграция `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` для существующих баз данных.
- Обновлена версия кэша Service Worker, чтобы браузер загрузил новую оболочку.
- Структурный тест дополнен проверкой контракта идемпотентности.
- Проверка `npm test` прошла в среде разработки. Реальный PostgreSQL/браузерный офлайн-прогон здесь не выполнялся.

## Честный статус готовности
Проект нельзя объявлять на 100% готовым к реальному использованию: не подключены AI-провайдер/ключи и интеграции носимых устройств; не выполнены production-развёртывание, настройка почты для восстановления доступа, полноценный push, аудит безопасности и end-to-end тестирование с PostgreSQL и телефонами. Это внешние и интеграционные задачи, которые нельзя достоверно закрыть только статической сборкой.
